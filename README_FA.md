# سامانه پیش‌ثبت‌نام گروه آمار — نسخه 0.5 Fresh Start

این بسته برای راه‌اندازی **کاملاً تازه** طراحی شده است. نیازی به اجرای SQL نسخه‌های 0.1 تا 0.4 یا فایل Upgrade نسخه 0.5 ندارد.

## نتیجه اجرای Fresh Setup

- تمام `registrations` قبلی حذف می‌شوند.
- تمام `registration_courses` قبلی حذف می‌شوند.
- جدول `admins` قبلی حذف و دوباره ساخته می‌شود.
- جدول `courses` قبلی حذف و دوباره ساخته می‌شود.
- ۳۰ درس اولیه فعلی دوباره درج می‌شوند تا سایت بلافاصله قابل استفاده باشد.
- پنل Admin از ابتدا قابلیت افزودن، ویرایش، فعال/غیرفعال و حذف درس را دارد.
- هیچ دانشجوی ثبت‌شده‌ای باقی نمی‌ماند.
- حساب‌های بخش Supabase Authentication به‌صورت خودکار حذف نمی‌شوند؛ در صورت نیاز آن‌ها را از Authentication → Users دستی حذف کنید.

## راه‌اندازی

### 1. تنظیم اتصال سایت
فایل `config.js` را باز کنید و مقادیر واقعی پروژه Supabase را وارد کنید:

```js
window.APP_CONFIG = {
  SUPABASE_URL: "https://YOUR_PROJECT_REF.supabase.co",
  SUPABASE_PUBLISHABLE_KEY: "sb_publishable_..."
};
```

هرگز Secret key یا service_role را در GitHub قرار ندهید.

### 2. صفر کردن و ساخت دیتابیس
در Supabase به `SQL Editor → New Query` بروید و **فقط** فایل زیر را اجرا کنید:

`supabase_fresh_setup_v0_5.sql`

این فایل مخرب است و داده‌های قبلی سامانه پیش‌ثبت‌نام را پاک می‌کند.

### 3. ساخت کاربر مدیر
در Supabase به `Authentication → Users → Add user` بروید، ایمیل و رمز مدیر را بسازید و کاربر را Confirm کنید.

سپس فایل `add_admin.sql` را باز کنید، ایمیل نمونه را با ایمیل واقعی مدیر جایگزین و Query را اجرا کنید.

### 4. تست محلی

```bash
python3 -m http.server 8000
```

صفحه دانشجو:
`http://localhost:8000/`

صفحه مدیر:
`http://localhost:8000/admin.html`

### 5. انتشار در GitHub Pages
تمام فایل‌های این پوشه را در ریشه Repository قرار دهید. اگر Pages قبلاً فعال است، کافی است فایل‌ها را Commit کنید.

## نکته مهم
برای نصب Fresh Start، فایل‌های `supabase_upgrade_*` عمداً در این بسته وجود ندارند تا روند راه‌اندازی گیج‌کننده نشود.
