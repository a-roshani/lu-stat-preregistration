# سامانه پیش‌ثبت‌نام گروه آمار — نسخه 1.0

این پوشه فقط فایل‌های قابل انتشار روی GitHub Pages را دارد.

## اتصال به Supabase
فایل `config.js` را باز کنید و فقط این دو مقدار را وارد کنید:

```javascript
window.APP_CONFIG = {
  SUPABASE_URL: "https://YOUR_PROJECT.supabase.co",
  SUPABASE_PUBLISHABLE_KEY: "sb_publishable_..."
};
```

از Secret key یا service_role در GitHub استفاده نکنید.

## فایل‌های قابل انتشار
تمام فایل‌های همین پوشه را در ریشه Repository قرار دهید. `index.html` باید مستقیماً در ریشه Repository باشد.

## امکانات دانشجو
- ثبت نام، نام خانوادگی، شماره دانشجویی و ورودی
- انتخاب چند درس
- کد ویرایش 4 تا 8 رقمی
- بازیابی و اصلاح ثبت‌نام قبلی
- پیام واضح پس از ثبت موفق

## امکانات مدیر
- مشاهده، جست‌وجو، ویرایش و حذف دانشجو
- مدیریت کامل دروس: افزودن، ویرایش، فعال/غیرفعال و حذف
- مدیریت کامل ورودی‌ها: افزودن، ویرایش، فعال/غیرفعال و حذف
- مشاهده تقاضای هر درس
- مشاهده تعداد و اسامی دانشجویان مشترک بین هر دو درس
- خروجی JSON مخصوص University Scheduler
- پشتیبان کامل JSON
- «شروع دوره جدید» برای پاک‌کردن همه ثبت‌نام‌های دانشجویان بدون حذف دروس، ورودی‌ها یا حساب مدیر

## هماهنگی با University Scheduler
شناسه‌های 30 درس و 9 ورودی اولیه مستقیماً از University Scheduler v1.44 استخراج شده‌اند. این شناسه‌ها پل اصلی تطبیق داده‌ها هستند. اگر درس یا ورودی جدیدی در سایت اضافه می‌کنید، بهتر است همان شناسه را در Scheduler نیز ایجاد کنید؛ در غیر این صورت Scheduler هنگام Import آن را هشدار می‌دهد و روابط ناشناخته را وارد Solver نمی‌کند.
