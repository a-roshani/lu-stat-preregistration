# سامانه پیش‌ثبت‌نام گروه آمار — v0.6 (Update / Preserve Data)

این بسته مخصوص ارتقای سایت موجود از v0.5 به v0.6 **بدون حذف هیچ دانشجو یا انتخاب درسی** است.

## نکته حیاتی
- هیچ SQL جدیدی برای این ارتقا لازم نیست.
- هیچ Reset یا Fresh Setup اجرا نکنید.
- داده‌های دانشجویان در Supabase هستند و تعویض فایل‌های GitHub آن‌ها را حذف نمی‌کند.
- فایل `config.js` فعلی سایت خودتان را نگه دارید. در این بسته فقط `config.example.js` وجود دارد تا تصادفی کلیدهای واقعی شما بازنویسی نشوند.

## فایل‌هایی که روی GitHub جایگزین می‌شوند
- `index.html`

## امکانات جدید v0.6
- نمایش نام و شماره دانشجویی افراد مشترک بین دو درس در پنل مدیر.
- تب «خروجی برنامه‌ریز».
- دانلود `preregistration_scheduler_*.json` برای University Scheduler v1.43.
- دانلود پشتیبان JSON از داده‌های فعلی که پنل مدیر می‌بیند.

فایل مخصوص Scheduler شامل اطلاعات شخصی دانشجویان است؛ آن را در GitHub عمومی قرار ندهید.
